개인정보처리방침

시행일: 2026년 10월 25일

쿠팡 영상 마스터(이하 "이 도구")는 운영자가 직접 관리하는 유튜브 채널을 위한 개인용 도구입니다. 이 문서는 이 도구가 Google 계정으로 받은 정보를 어떻게 쓰는지 설명합니다.

1. 요청하는 권한과 쓰는 이유

  • YouTube 동영상 업로드 (youtube.upload): 운영자가 만든 상품 추천 영상을 운영자의 채널에 올리고 썸네일을 등록합니다.
  • YouTube 계정 관리 (youtube.force-ssl): 올린 영상에 구매 링크 댓글을 달고, 영상의 공개 설정과 조회수를 확인합니다.
  • YouTube 분석 보기 (yt-analytics.readonly): 운영자 채널의 조회수·시청 시간·유입 경로 통계를 확인해 어떤 영상을 만들지 정합니다.

2. 저장하는 정보

  • 유튜브 연결 토큰(갱신 토큰)은 암호화해서 운영자 PC의 데이터베이스에만 저장합니다.
  • 채널 이름·채널 ID, 올린 영상의 ID와 조회수·분석 통계를 운영자 PC에 저장합니다.
  • Google 계정 비밀번호는 받지도 저장하지도 않습니다.

3. 제3자 제공

Google 사용자 데이터를 판매하거나 광고 목적으로 쓰지 않으며, 제3자에게 제공하지 않습니다. 이 도구의 Google API 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 연결 해제와 삭제

이 도구의 채널 화면에서 연결을 해제하면 저장된 토큰을 지웁니다. 또한 Google 계정 권한 페이지에서 언제든지 이 도구의 접근 권한을 취소할 수 있습니다.
