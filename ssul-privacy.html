썰쇼츠 마스터 개인정보처리방침

시행일 2026년 10월 25일

썰쇼츠 마스터(이하 "앱")는 운영자 본인이 자기 유튜브 채널에 쇼츠 영상을 올리고 성과를 확인하기 위해 쓰는 개인용 도구입니다.

1. 받는 권한과 쓰는 곳

  • YouTube 업로드 (youtube.upload): 앱에서 만든 영상을 내 채널에 올리고 예약 공개를 설정합니다.
  • YouTube 관리 (youtube.force-ssl): 올린 영상에 내 계정으로 댓글을 하나 답니다.
  • YouTube 분석 읽기 (yt-analytics.readonly): 내 영상의 조회수·시청 비율·구독자 증가를 읽어 통계 화면에 보여 줍니다.

이 밖의 용도로는 쓰지 않으며, 구글 계정 비밀번호는 받지 않습니다.

2. 보관

  • 구글이 발급한 갱신 토큰(refresh token)만 암호화해 앱 서버에 보관합니다.
  • 채널 이름·채널 ID와 영상별 통계 숫자를 앱 화면에 보여 주려고 저장합니다.
  • 채널 설정에서 '연결 끊기'를 누르면 토큰을 지웁니다. 구글 계정 설정(myaccount.google.com/permissions)에서도 언제든 접근을 끊을 수 있습니다.

3. 제3자 제공

YouTube API 로 받은 정보를 다른 사람이나 회사에 주거나 팔지 않습니다. 광고에 쓰지 않습니다.

4. 구글 정책 준수

앱이 Google API 에서 받은 정보를 쓰는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. YouTube 정보 이용은 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다.
